# Análisis exploratorio de videojuegos

## Objetivo

Explorar las ventas de videojuegos por región, plataforma y género mediante estadística descriptiva y visualizaciones.

## Análisis incluidos

- Dimensiones, tipos de datos y valores nulos.
- Medidas de tendencia central y dispersión.
- Histogramas de ventas y puntajes.
- Diagramas de caja y detección de valores atípicos con IQR.
- Frecuencias por plataforma y género.
- Interpretación comercial de los resultados.

## Estructura

- `notebooks/desafio_videojuegos_EDA_Hector_Lopez.ipynb`: análisis completo.
- `data/videojuegos.csv`: dataset requerido, no incluido todavía.

## Ejecución

Coloca el archivo con el nombre `videojuegos.csv` dentro de `data/` y ejecuta el notebook desde Jupyter o Google Colab.

## Competencias demostradas

EDA, estadística descriptiva, tratamiento de datos faltantes, visualización e interpretación de resultados.
