# Portafolio de Análisis de Datos | Héctor López

Portafolio de proyectos desarrollados durante mi formación como **Técnico en Data Science**, orientado a demostrar competencias en análisis exploratorio, preparación de datos, visualización, reducción de dimensionalidad y aprendizaje automático.

Mi perfil se enfoca actualmente en oportunidades como **Analista de Datos Junior, Analista BI y Control de Gestión**, combinando análisis técnico con interpretación de negocio y comunicación clara de resultados.

## Proyectos destacados

| Proyecto | Problema abordado | Metodología y herramientas | Valor para el negocio |
|---|---|---|---|
| [PCA aplicado a Ames Housing](pca-ames-housing/) | Analizar un conjunto de datos inmobiliarios con numerosas variables numéricas. | Python, Pandas, Scikit-learn, imputación, `StandardScaler`, PCA y Matplotlib. | Permite reducir la complejidad de los datos, identificar los factores que concentran mayor información y facilitar análisis posteriores. |
| [Análisis exploratorio de videojuegos](analisis-exploratorio-videojuegos/) | Explorar el comportamiento de las ventas según región, plataforma y género. | Python, Pandas, estadística descriptiva, tratamiento de valores faltantes, detección de valores atípicos y visualización. | Facilita la identificación de patrones comerciales y diferencias entre segmentos del mercado. |
| [Modelo de aprobación crediticia](https://github.com/oreon36/modelo-crediticio-machine-learning) | Clasificar solicitudes de crédito mediante variables financieras y demográficas. | Python, Pandas, Scikit-learn, `Pipeline`, `ColumnTransformer`, `StandardScaler`, `OneHotEncoder`, Regresión Logística y validación cruzada estratificada. | Demuestra cómo estructurar un proceso reproducible para apoyar la evaluación de solicitudes y analizar el equilibrio entre distintos tipos de error. |

## Cómo ejecutar los proyectos

1. Clona este repositorio:

```bash
git clone https://github.com/oreon36/portafolio-analisis-datos.git
cd portafolio-analisis-datos
```

2. Instala las dependencias:

```bash
pip install -r requirements.txt
```

3. Abre Jupyter Notebook:

```bash
jupyter notebook
```

4. Ingresa en la carpeta del proyecto y ejecuta su notebook.
